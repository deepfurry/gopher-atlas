## 项目定位

GopherAtlas 是一个面向 Go 开发者的高质量技术文章精选站，聚焦长期有效、值得反复阅读的内容沉淀。

项目不以“收录数量”为目标，而更重视内容筛选的准确性、话题组织的清晰度，以及阅读路径的可用性。精选文章不是转载正文，而是对优质第三方 Go 技术文章进行统一整理、话题编排、评级与导读，帮助读者更高效地发现高价值内容。

我们希望 GopherAtlas 能够提供一种更稳定的阅读入口：在面对分散的博客、官方文章和社区输出时，读者可以通过专题、标签、搜索与评级，快速定位值得优先阅读的文章。

## 收录标准

GopherAtlas 默认优先收录符合以下条件的内容：

- 技术内容准确，结论与示例具备可靠性
- 解释清晰，能够帮助读者理解原理、背景与设计取舍，而不仅是罗列 API 或代码片段
- 对实际工程实践具有启发意义，而非纯营销、浅层搬运或低信息密度内容
- 具备相对长期的参考价值，避免过度依赖短期热点
- 优先考虑官方作者、核心贡献者、资深工程师或长期稳定输出者的内容

对于明显过时、信息失准、重复度过高或参考价值有限的文章，原则上不纳入正式收录范围。

## 评级规则

GopherAtlas 使用统一的推荐评级来表达文章的阅读优先级。评级用于辅助读者建立阅读顺序，不代表绝对分数，也不构成对文章观点“正确与否”的简单判断。

- `S+`：极强推荐，具有很高的长期价值与优先阅读价值
- `S`：高质量核心文章，建议完整阅读
- `A+`：内容优秀，适合作为专题重点延伸阅读
- `A`：质量稳定，适合作为补充阅读
- `B+ / B`：具有一定参考价值，但优先级相对较低
- `C+ / C`：可作为背景材料或补充材料使用

评级会综合考虑以下因素：

- 内容质量与准确性
- 技术深度与信息密度
- 可读性与结构清晰度
- 对工程实践的帮助程度
- 长期参考价值

## 说明

GopherAtlas 的目标不是替代原始文章来源，而是为读者提供一个更高效、更有组织的入口。所有内容的版权与最终解释权归原作者及原始发布方所有。

如果你认为某篇文章值得收录，或发现现有内容存在信息错误、链接失效或话题编排不合理的问题，欢迎通过仓库提交 Issue 或 Pull Request。

## 三条阅读路径

精选文章提供外链导航、收录理由与编辑点评；话题专区只编排精选文章，提供推荐顺序；学习随笔记录原创实践，按分组连续阅读。
